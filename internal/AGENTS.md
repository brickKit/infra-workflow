# internal/：业务模块

统一待办的业务，每个模块一个包。只给本仓库引用（Go 的 `internal`）：别的组件编译期就引用不了（决定 0101）。

## 模块

| 包 | 一句话 | 依赖（本组件内） |
| --- | --- | --- |
| `worklist` | 用户面：我的待办、已办、读取一个任务 | `core` |
| `projections` | 收任务投影与心跳、发布者核对、按版本覆盖、被拒的投影 | `core`、`sources` |
| `sources` | 部署的发布方配置与发布者核对（纯函数） | `core` |
| `core`（共用） | 名字、资源与操作、配置键、错误与校验、游标、`Base` | — |

分层（每个包只引用比它低的层，没有环）：

| 层 | 包 |
| --- | --- |
| 3 | `worklist`、`projections` |
| 2 | `sources` |
| 1 | `core` |

核对：`go list -f '{{.Imports}}' ./internal/<包>`。

## 共同的写法

- **每个模块的函数先收 `m *core.Base`**（运行时、配置的发布方、阈值），入口包的 `Module` 持有它、登记时适配。
- **只读投影里要用的字段**：投影原样保存（`task.data`），读取时原样答回；列只放查询要的（状态、候选、类型、法人、截止、决定者）。
- **列表按游标分页**（`core.Cursor`、`core.FromCursor`），不用偏移量。
